# AgentSynth sound packs

Free sound packs for the [AgentSynth](https://github.com/Diabl0269/agentsynth) Sampler. Downloading from the app is planned: the app will list these packs and install one when you ask it to. Until then you can unzip a pack into the app's SoundPacks folder (on macOS, ~/Library/Application Support/Agent Synth/SoundPacks).

Each pack is a release of this repository. The release holds the pack as a zip and a `.sha256` file that the app checks before installing. `index.json` lists every pack with its version, size, download link and checksum.

## Credits

The Core instruments pack is built from public-domain (CC0) recordings:

- **VSCO 2 Community Edition** by Versilian Studios: strings, brass, woodwinds and plucked bass. The upright piano is by Simon Dalzell of Ivy Audio.
- **Virtuosity Drums** by Versilian Studios: drummer Austin McMahon, recorded at Virtuosity Musical Instruments.
- **Black and Green Guitars** by Karoryfer Samples: recorded by Brian Wood.

For AgentSynth, the recordings were trimmed, looped, level-matched and compressed to FLAC, and new SFZ maps were written for them. These packs are not the original libraries, and their makers do not endorse them. Each pack's `LICENSES/` folder has the original licence texts and a `SOURCES.md` that lists every file used and what was changed.
